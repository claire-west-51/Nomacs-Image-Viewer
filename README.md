## 📖 About

Nomacs is an open source image viewer built by the Nomacs project team. It handles JPEG, PNG, TIFF, GIF, BMP, WebP, RAW and many other formats, supports synchronized multi-panel view, basic adjustments like resize, crop, rotate and color tweaks, plus a thumbnail sidebar for quick navigation through folders. Recent builds include improved RAW decoding, a refreshed settings panel and faster folder indexing on large libraries.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes without finishing | Temporarily close other apps, then run the setup file again as administrator. |
| Nomacs does not open after install | Search "Nomacs" in the Start menu, right click and choose **Open file location**. |
| Images open in the wrong app | Right click an image, choose **Open with**, then **Choose another app** and select Nomacs. |
| RAW files show blank previews | Open **Settings**, then **Formats** and enable RAW decoder support. |
| Thumbnail sidebar is slow on big folders | Reduce thumbnail size in **View**, then **Thumbnail size**. |
| Interface text looks too small on 4K display | Enable High DPI scaling in the shortcut properties, or set a larger font in **Settings**. |
